# MyModules

Une réimplémentation progressive de modules standards de la bibliothèque Python (`statistics`, `math`, `random`, etc.), dans le but de mieux comprendre leur fonctionnement interne et de construire une librairie pédagogique, modulaire et extensible.

---

## 🚀 Objectif du projet

Ce projet vise à **recréer from scratch des modules Python standards** afin de :

- Comprendre les algorithmes et structures internes des fonctions standardes
- Améliorer mes compétences en algorithmique et en mathématiques appliquées
- Construire une petite bibliothèque personnelle réutilisable
- Expérimenter des implémentations nouvelles

---

## 📦 Modules disponibles

### 📊 statistics (en cours)
Reproduction de fonctions du module `statistics` de Python.

Exemples de fonctions implémentées :
- Moyenne (`mean`)
- Médiane (`median`)
- Variance (`variance`)
- Écart-type (`stdev`)
etc...
